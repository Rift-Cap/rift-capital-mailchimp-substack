Neolabs raise billions on a research agenda. The valuation column ranks them all as one trade.

| | | | Rift Capital | RIFT CAPITAL | | --- | --- | | MARKET INSIGHT · NO. 1 · SEPT 2026 | | --- | --- | --- | --- | | | |  | | --- | | | ARTIFICIAL INTELLIGENCE · PRIVATE MARKETS Frontier Labs: The Billion-Dollar Bet on Discovery A new generation of AI companies is raising industrial-scale capital on the strength of a research agenda. Some already sell models, software or scientific services. Others are raising hundreds of millions before deciding what they will sell. The market has a name for them, neolabs, and one instrument for ranking them: a column labelled valuation. That column tells you very little.  By Paul Ravignon, Chief of Staff | | |  | | --- | | | 01 One trade, or many bets The valuation column hides the difference  The column sets a company running robotic experiments beside one building a mathematical reasoning system, as though the two faced the same costs, the same evidence and the same clock. A proposed term sheet sits next to a closed round, next to an estimated secondary price.  The ambitions vary widely. Machines that understand physical environments. Systems that learn from fewer examples. Robots that carry skills from one task to another. Models that design molecules, prove mathematics, operate software or improve the research process that created them. | | | The financing makes this look like one trade. Scientifically it is a set of competing bets. | | --- | | | 02 What each lab can learn The question the valuation column cannot answer  The question that separates these companies is what each one could learn that is hard to learn anywhere else. Some will accumulate experimental data. Others will develop environments where models can practise, reliable ways to judge their answers, or architectures that make a useful capability cheaper. Their advantage, if it comes, will be the capacity to keep making progress in a field that rewards it.  This is a healthy change in the shape of the industry. Building at the frontier still demands substantial resources. But there are more frontiers worth pursuing than the market for a universal assistant, and more ways to organise the research needed to reach them. Independent teams can now finance those attempts at serious scale.  The price of admission is often extraordinary. | | | 03 Three questions before the valuation How we read a number in this market   | 01 | What kind of number is this? A company press release, a rumoured negotiation, a filing with the regulator and an entry in a private database all end up printed as the same headline valuation. Core Automation’s filing shows $432.1m of shares sold. $135.3m of that is old convertible notes turning into equity, not new money arriving. | | --- | --- | |  | | | 02 | Is the advantage cumulative? A lab that gets better at investigating its domain has many ways to stay useful. A single model gets overtaken, and a benchmark score says nothing about whether the method transfers to a larger, messier problem. | |  | | | 03 | What does a good outcome look like from here? A high entry price limits dilution and raises the bar at the same time. SAP bought Prior Labs in July and committed more than €1bn over four years to develop it, at an undisclosed price. Not every good outcome here is an IPO, and an entry valuation set high enough turns an excellent scientific result sold to an industrial buyer into a poor financial one. |  | We underwrite the learning loop rather than the valuation: what does the lab learn from each attempt, and does that make the next attempt cheaper or better? Asked that way, the labs stop looking interchangeable.The full article follows that question across the whole cohort. Yann LeCun raising $1.03bn to teach machines how the physical world behaves. Jeff Dean building a company whose first customer is itself. Periodic Labs running robotic chemistry in Menlo Park and reporting a twentyfold jump in reading its own experiments. Skild crossing $100m of recurring revenue, ten months after its first deployment. Every financing figure is sourced, dated and labelled, so you can tell which prices are facts and which are rumours.
